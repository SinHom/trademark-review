## 条号映射

2019 版与 2026 版条号不同，**不要凭记忆引用**。唯一事实来源是
[`../article_map.json`](../article_map.json)。关键差异：

| 检查项 | 2019 版 | 2026 版 |
|---|---|---|
| 禁用标志总则 | 第十条第一款 | 第十五条 |
| 国家名称等 | 第十条第一款第一项 | 第十五条第一款第二项（新增党旗党徽为第一项） |
| 欺骗性标志 | 第十条第一款第七项 | 第十五条第一款第八项 |
| 县级以上地名 | 第十条第二款 | 第十六条 |
| 显著特征 | 第十一条 | 第十七条 |
| 通用名称 | 第十一条第一款第一项 | 第十七条第一款第一项 |
| 功能性限制 | 第十二条 | 第十八条 |
| 相同/近似 | 第三十条 | 第二十条 |

## 关于审查审理指南的 OCR 文本

官方 PDF 为 422 页扫描件，无文字层，须经 OCR。当前文本：

- 由 `scripts/fetch_guideline.sh` 生成，可随时重跑复现
- 200dpi + Tesseract（chi_sim），**未做逐字人工校对**
- 存在形近字误识（如"旗帜"→"旗帆"、"徽记"→"微记"）
- 每页有 `<!-- pN -->` 标记，对应官方 PDF 页码，便于回溯

**使用规则：用于检索、定位、通读；对外引用条文时必须回查官方 PDF 原文。**

## 更新纪律

法规修订时：

1. 下载新文本 → 覆盖对应 `.md`
2. 更新 `references/article_map.json` 的映射与版本表
3. 更新 `config.yaml` 的 `trademark_review.law.version`
4. 跑 `python tests/test_review.py`，`test_article_map_consistency` 会校验条号能在原文中定位
5. 在 `CHANGELOG.md` 记录变更原因
