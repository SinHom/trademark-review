# 示例产物

全部由 `bash scripts/demo.sh` 生成，无手工编辑。任何人克隆仓库后可一键重放。

| 文件 | 输入 | 结论 | 说明 |
|---|---|---|---|
| `case-01-clean.txt` | 云图智能 / 9,42 类 | 低风险 | 规则层无阻碍；在先商标如实标注"未检索" |
| `case-02-geographic.txt` | 北京烤鸭 / 30 类 | 条件性风险 | 含省级地名，须确认是否具有其他含义 |
| `case-03-hard-block.txt` | 特供产品 / 35 类 | 不得注册 | 欺骗性标志，绝对阻断，不给成功率 |
| `case-04-national.txt` | 中国移动 / 38 类 | 条件性风险 | 含国家名称但非整体相同，按指南第三章留例外判断空间 |
| `case-05-generic.txt` | 苹果 / 31 类 | 高风险（缺乏显著特征） | 31 类通用名称；同样输入在 9 类不误伤 |
| `sample-report.docx` | 云图智能 / 9,42 类 | — | Word 报告：结论摘要表、逐项法条、检查范围、结论边界、免责声明 |

## 为什么用这几个案例

它们覆盖了工具会做出的五种不同判断，而不是五个"看起来一样"的成功例子：

- **硬阻断**（特供产品）：绝对不得注册，成功率显示"不适用"
- **条件性**（北京烤鸭 / 中国移动）：取决于人工确认的事实，给判断路径而不是结论
- **显著特征**（苹果 / 31）：通用名称，但同名词在 9 类不误伤
- **干净**（云图智能）：仍然明写在先商标没查

最后一条是关键——**没做的事必须写出来**，这是这个工具与"随便给个分数"的工具的区别。
